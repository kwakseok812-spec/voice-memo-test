# 음성 메모 정리 (테스트판) — voice-memo-test

말하면 → 글자로 바꾸고(STT) → 핵심 요약·할 일·결정사항으로 정리해 보여주는 **웹앱 테스트판**입니다.
장차 만들 "나만의 통합 메신저 앱"의 **녹음·분석 기능을 먼저 떼어 실험**하는 첫 단추입니다.

- 대상 기기: 갤럭시 폴드8 등 **안드로이드 Chrome** (PC Chrome도 가능)
- 방식: **완전 클라이언트 / 서버·API 키·비용 없음** (방법 A = 앱에서 직접 녹음)
- 아이폰 Safari는 음성 인식(Web Speech API) 미지원 — 이 경우 "예시로 정리해 보기"만 동작

## 쓰는 법
1. Chrome에서 주소로 접속 → 처음 한 번 **마이크 사용 "허용"**.
2. **🎙️ 녹음 시작** → 말하기 → **⏹️ 녹음 정지**.
3. 정지하면 자동으로 아래에 **핵심 요약 / 할 일 / 결정사항 / 자주 나온 단어**가 정리됩니다.
4. 전사 원문은 직접 고칠 수 있고, 고친 뒤 **다시 정리하기**를 누르면 재정리됩니다.
5. **결과 복사**로 정리본+원문을 통째로 복사할 수 있습니다.
6. **저장·내보내기**: `💾 이 메모 저장`(폰 안에 기록), `📄 Word`·`📊 PPT(초안)`으로 파일 저장/공유, `📝 기록(MD)`은 텍스트 기록용.
7. **지난 메모**: 저장한 메모가 목록에 쌓이고, 누르면 다시 열어 Word/PPT로 내보내거나 삭제할 수 있습니다.
8. 마이크 없이 기능만 보려면 **예시로 정리해 보기**.

## 홈 화면에 앱처럼 설치 (교수님용)
1. 갤럭시 **Chrome**에서 이 앱 주소를 엽니다(https 주소여야 함).
2. 오른쪽 위 **⋮(점 3개) 메뉴 → "앱 설치" 또는 "홈 화면에 추가"**를 누릅니다.
3. 홈 화면에 **파랑 마이크 아이콘**이 생기고, 누르면 주소창 없는 전체화면 앱처럼 열립니다.
4. ※ 음성 인식은 **인터넷 연결**이 있어야 동작합니다(화면은 오프라인에서도 열림).

## 파일 구조 (통합 대비 — 모듈 분리)

이 앱은 통합 메신저 앱으로 옮기기 쉽도록 **두 개의 독립 모듈**로 나눠 만들었습니다.
`js/app.js`(화면 연결)는 업무 논리를 갖지 않고 두 모듈을 호출·표시만 합니다.

| 파일 | 역할 | 통합 시 |
|---|---|---|
| `js/recorder.js` | **녹음/음성인식 모듈** (`RecordingModule`). 말소리→글자만 담당. `start()`/`stop()` + 5개 콜백(`onStatus/onInterim/onFinal/onError/onLevel`)이 유일한 창구. 현재는 브라우저 내장 Web Speech API(무료). | 이 파일만 통째로 교체하면 됨. 예: Web Speech → (녹음 파일 업로드 + 서버 STT). 바깥 코드는 그대로. |
| `js/analyzer.js` | **분석/정리 모듈** (`AnalysisModule.analyze(text)`). 글자 뭉치→`{summary, todos, decisions, keywords, sentences}`. 현재는 규칙 기반(키워드·문장 점수). | 내부만 Claude API 호출로 바꾸면 (입출력 모양 동일) 정리 품질만 향상. |
| `js/exporter.js` | **내보내기 모듈** (`ExportModule`). 정리 데이터→Word(.docx)/PPT(.pptx)/MD 파일. CDN 라이브러리(docx, pptxgenjs)를 필요할 때만 로드, 실패 시 한국어 안내. Web Share→다운로드 폴백. | 형식 추가/교체가 이 파일 안에서 끝남. |
| `js/history.js` | **기록 모듈** (`HistoryModule`). 완료 메모를 localStorage에 저장·목록·삭제. `save()` 안에 **사무소 자동전송 다리 자리(주석 표시)**를 남겨 둠(교수님 승인 대기). | 저장소만 통합 앱 DB로 교체하면 됨. |
| `js/app.js` | 화면 글루. 버튼→모듈 호출→결과 렌더링. | 새 앱 화면에 맞춰 이 부분만 다시 작성. |
| `index.html`, `css/styles.css` | UI(한국어·큰 버튼). | 통합 앱 디자인에 맞춰 교체. |
| `manifest.json`, `sw.js`, `icons/` | PWA(홈 화면 설치)용 설정·서비스워커·아이콘. | 통합 앱 설정으로 교체. |

> 핵심 설계: **모듈의 인터페이스(입력·출력·콜백)를 고정**해 두었으므로,
> 나중에 STT 엔진이나 분석 엔진을 바꿔도 나머지 코드를 건드리지 않습니다.

## 비용 / 설치 (정직 보고)
- **지금 이 테스트판: 완전 무료·무설치.** 서버도, 유료 API 키도 필요 없습니다.
  - STT: 브라우저(Chrome) 내장 Web Speech API 사용. 단, 구글 음성엔진을 경유하므로 **인터넷 연결이 필요**합니다.
  - 분석: 브라우저 안에서 규칙 기반으로 처리(오프라인 가능).
- **나중에 품질을 올리려면(선택)**: 정리·분석을 Claude API로 바꾸면 훨씬 똑똑해지지만, 그때는 API 사용료(사용량 기준)와 키를 넣을 작은 서버가 필요합니다. — 통합 단계에서 별도 검토.
- **내보내기(Word/PPT)**: 무료 오픈소스 라이브러리(docx, pptxgenjs)를 CDN에서 불러와 **브라우저 안에서** 파일을 만듭니다. 서버·유료 요소 없음. 인터넷이 막히면 그 버튼만 실패하며 한국어로 안내합니다(다른 기능은 정상).
- **PDF는 뺐습니다**(교수님 확정): 보기용은 Word·PPT로 충분하므로 한글 폰트 임베드 작업을 하지 않아 앱이 가볍습니다.
- **기록(지난 메모)**: 이 폰(브라우저) 안에만 저장됩니다. 서버로 보내지 않습니다. "완료된 메모를 사무소로 자동 전송"하는 다리는 교수님 승인 후 붙일 예정이며, `history.js`에 자리만 주석으로 표시해 두었습니다.

## PWA(설치) 요건 점검
- ✅ manifest.json(name·아이콘 any/maskable·standalone·theme_color) · ✅ 서비스워커(sw.js) · ✅ 192/512 아이콘 · ✅ https(GitHub Pages).
- 이 요건이 갖춰지면 갤럭시 Chrome이 "앱 설치"를 제안합니다.
- ⚠️ 서비스워커·설치는 **https 또는 localhost**에서만 동작합니다. 개발용 임베디드 브라우저 등 일부 환경에서는 서비스워커 등록이 막힐 수 있으나, 실제 갤럭시 Chrome + https(GitHub Pages)에서는 정상 등록됩니다.

## Web Speech API의 한계 (테스트 전 알아둘 점)
- **긴 녹음**: 안드로이드 Chrome은 잠깐 조용하면 인식이 끊길 수 있어, 코드에서 **자동 재시작**으로 이어붙입니다(완벽하진 않음).
- **화면 꺼짐/백그라운드**: 화면이 꺼지거나 다른 앱으로 넘어가면 녹음이 멈출 수 있습니다. 회의 전체 녹음보다는 **짧은 메모**에 우선 적합합니다.
- **정확도**: 조용한 환경·또박또박 말할수록 좋습니다. 전문용어·숫자는 오인식될 수 있어 **전사 원문을 직접 고치는 칸**을 두었습니다.
- 이 한계가 실제 용도에 부적합하다고 판단되면, "녹음 파일 업로드 → 서버 STT(정확도 높음, 비용 발생)" 방식으로 `recorder.js`만 교체하면 됩니다.

## 배포 (교수님 승인 후)
현재는 **로컬 완성 상태이며 배포하지 않았습니다.** 공개는 교수님 승인 사항입니다.
정적 파일(HTML/CSS/JS)뿐이라 GitHub Pages 등 정적 호스팅에 그대로 올라갑니다.

절차(예: GitHub Pages):
1. GitHub 저장소에 이 폴더 내용 업로드(dmu-bio 조직 또는 개인 계정).
2. Settings → Pages → 브랜치 지정 → 저장.
3. 발급되는 주소(예: `https://<계정>.github.io/voice-memo-test/`)를 폰 Chrome에서 열기.
4. ⚠️ 마이크는 **https 주소**에서만 동작합니다(GitHub Pages는 https 기본 제공).

## 로컬에서 확인하기
`file://`로 바로 열면 브라우저 보안 때문에 마이크가 막힐 수 있으니, 간단한 로컬 서버로 엽니다.
```
cd voice-memo-test
python -m http.server 8791
# 브라우저에서 http://localhost:8791/index.html
```
